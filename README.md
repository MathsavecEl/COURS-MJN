# COURS MJN — Mathématiques interactives

Site mobile de ressources pédagogiques de M. AHA MAJANI, sans compte élève. Il contient les classes 4e (416), 3e (306 et 312), Seconde et Première spécialité.

## Publication

Publie tout le contenu du dossier sur GitHub Pages (HTTPS). Le site est aussi une PWA : sur Android, ouvre l'adresse dans Chrome puis choisis **Installer l'application** ou **Ajouter à l'écran d'accueil**. Les pages et exercices sont mis en cache pour une utilisation hors ligne après un premier chargement, sous réserve des ressources externes.

## Application Android APK

Le projet Android séparé se trouve dans `android-maths`. Il intègre les pages HTML dans l'application. Voir `README-APK.md` pour lancer la compilation de l'APK avec GitHub Actions.
